Self-hosted OCR assets for reading scale displays in the user's browser.
Tesseract.js 6.0.1 — Apache-2.0, https://github.com/naptha/tesseract.js
Tesseract.js-core 6.0.0 — Apache-2.0, https://github.com/naptha/tesseract.js-core
English tessdata_fast 4.1.0 — Apache-2.0, https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0
The English model is restricted to numeric scale readings by the application.
Images are processed locally and are not uploaded by the scale reader.
